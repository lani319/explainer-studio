# Example — Constitution of the Republic of Korea, Chapter 1

The General Provisions (Articles 1–9) in five languages, made with this tool.

| file | |
|---|---|
| `script.ko.md` | base script — quotes the Korean text verbatim |
| `script.en.md`, `script.ja.md`, `script.zh.md`, `script.es.md` | translations with the same sections and line counts |
| `out/*.mp4`, `out/*.srt` | rendered videos and subtitles |

Rebuild:

```bash
python skills/explainer/scripts/cli.py all examples/kr-constitution-ch1 --lang all
```

## Source and rights

- Text: 대한민국헌법 (Constitution No. 10, wholly amended 29 Oct 1987, in force 25 Feb 1988), as published by the Korean Law Information Center ([law.go.kr](https://www.law.go.kr/lsEfInfoP.do?lsiSeq=61603)); retrieved from [legalize-kr/legalize-kr](https://github.com/legalize-kr/legalize-kr) (`kr/대한민국헌법/헌법.md`).
- The Constitution and statutes are not protected by copyright in Korea (Copyright Act, Article 7).
- The English, Japanese, Chinese and Spanish texts are **our own unofficial translations**, marked as such on screen. They are for illustration and are not legal translations.
- Narration describes what the articles say; it does not interpret them.
